# Welyz // Portfólio Conceitual Antigravity

> **Engenharia de Software de Alta Performance, Sistemas de Missão Crítica & Rigor Estético de Vanguarda.**

Este repositório contém a implementação completa do portfólio conceitual da iniciativa **Antigravity**, projetado como uma Single Page Application (SPA) em **Next.js 14**, **Tailwind CSS**, **TypeScript** e **Lucide React**, estruturada rigorosamente nos cinco atos do Plano Mestre de Execução.

---

## 🏛️ Os 5 Atos da Aplicação

1. **Ato 1 — Hero Conceitual & Manifesto:**
   - Efeito de iluminação dinâmica (spotlight suave) acompanhando as coordenadas do mouse.
   - Monograma vetorial *Welyz* sobre padrão de trevo bordô profundo (`#2A080C`) e ouro sand (`#E4B276`).
   - Tese de engenharia e autoridade técnica imediata.

2. **Ato 2 — The Engineering Matrix:**
   - Cockpit com indicadores consolidados em tempo real (460+ arquivos, ~605k tokens, 16 polos, 100% trilha forense).
   - Catálogo de 5 padrões arquiteturais comprovados em produção (JSON Diff, Validação Temporal, AST Tokenizer, Repository Pattern, Gamificação).
   - Matriz técnica de linguagens, frameworks, persistência e segurança.

3. **Ato 3 — Deep-Dive Case Studies:**
   - Apresentação técnica imersiva dos cinco sistemas desenvolvidos:
     - **Construindo Campeões (SEMTEL / Prefeitura de Porto Velho):** Gestão pública socioesportiva com RBAC e trilha forense.
     - **Dev Automation Kit (v0.1.4-alpha):** Estação de IA desktop offline para higienização e tokenização de AST.
     - **WLW PRO:** SaaS de hospitalidade com algoritmo matemático anti-overbooking e Central WhatsApp.
     - **Borü Centro de Combate:** Ecossistema de artes marciais com chamada em 1 clique e Streak do Guerreiro.
     - **Zapp Cidadão ON:** Atendimento cívico e zeladoria com protocolos unificados e mapas de calor Leaflet.
   - Lightbox de alta resolução para inspeção detalhada das interfaces operacionais.
   - Snippets interativos de código de produção para cada caso.

4. **Ato 4 — The Developer Lab:**
   - Simulador interativo do **Dev Automation Kit** em janela estilo workstation desktop.
   - Árvore de arquivos interativa em cascata com seleção granular de pastas.
   - Cálculo dinâmico em tempo real de contagem de arquivos, volume textual em MB e tokens BPE.
   - Simulação de higienização de chaves de API, variáveis de ambiente e compilação de contexto.

5. **Ato 5 — Terminal Executivo & Contato:**
   - Ponto de conversão com cartões de serviços inspirados no design do Borü.
   - Terminal funcional de despacho com geração de protocolo rastreável de atendimento.
   - Links diretos para WhatsApp Corporativo, GitHub, LinkedIn e E-mail.

## 🛠️ Stack Tecnológica

- **Framework:** Next.js 14 (App Router)
- **Linguagem:** TypeScript 5 (Strict Mode)
- **Estilização:** Tailwind CSS com Design Tokens customizados (Burgundy, Sand Gold, Obsidian, Crimson, Emerald)
- **Ícones:** Lucide React
- **Animações:** CSS Transitions & Framer Motion ready

## 🚀 Como Executar Localmente

### Pré-requisitos
- Node.js 18+ (recomendado Node.js 20+ ou 22+)
- npm ou yarn

### Instalação
```bash
# Instalar dependências
npm install
```

### Desenvolvimento
```bash
# Iniciar servidor de desenvolvimento na porta 3000
npm run dev
```
Acesse [http://localhost:3000](http://localhost:3000) no seu navegador.

### Build de Produção
```bash
# Gerar bundle otimizado de produção
npm run build

# Executar build de produção
npm run start
```
